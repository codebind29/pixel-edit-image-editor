# PixelEdit – Image Editor

PixelEdit is a modern, Canva-inspired single-page image editor built using HTML, CSS and JavaScript.

It allows users to upload an image, apply real-time adjustments and presets, reset changes and download the edited image.

## Features

- Upload images
- Real-time image preview
- Brightness adjustment
- Contrast adjustment
- Exposure adjustment
- Saturation adjustment
- Hue rotation
- Blur effect
- Grayscale effect
- Sepia effect
- Opacity adjustment
- Invert effect
- Preset filters
- Reset image adjustments
- Download edited image
- Responsive single-page interface
- Client-side image processing using HTML Canvas

## How to Use

1. Open PixelEdit.
2. Click **Upload Image**.
3. Select an image from your device.
4. Adjust the available sliders.
5. Try different presets.
6. Use **Reset** to restore the original adjustments.
7. Click **Download** to save the edited image.

## Highlights

The application uses the HTML Canvas API to render the uploaded image and apply visual effects directly in the browser.

All image processing happens on the client side, so the image does not need to be uploaded to a server.
